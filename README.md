# Lean Late Game

Мод для **Hearts of Iron IV**, цель которого — уменьшить нагрузку на CPU в поздней игре (примерно 1943+), когда игра начинает фризить и замедляться.

> Статус: **0.1.0, каркас**. Пока в репозитории структура и документация, правки ИИ и скриптов добавляются по плану из `docs/ROADMAP.md`.

## Идея

Движок HoI4 в основном однопоточный, поэтому мод не ускорит его ядро. Но можно сократить объём работы, которую игра считает каждый день:

1. Более лёгкий ИИ у второстепенных стран.
2. Меньше, но крупнее дивизий у ИИ (меньше расчётов снабжения, боёв и путей).
3. Разрежение тяжёлых `on_daily` / `on_weekly` скриптов.
4. Настройки в `defines` (частоты пересчётов).

Мод не должен менять баланс и ход истории заметнее, чем это необходимо.

## Установка (для разработки)

1. Склонируй репозиторий, например в `Documents/GitHub/lean-late-game`.
2. Скопируй `launcher/Lean_Late_Game.mod` в `Documents/Paradox Interactive/Hearts of Iron IV/mod/`.
3. В скопированном файле поправь `path=` на путь к папке репозитория (с прямыми слэшами).
4. Запусти лаунчер HoI4 и включи мод в плейсете.
